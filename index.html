Projects

Enterprise Knowledge AI

Ask questions about company documents and get answers that cite the exact sentence they came from, or an honest "not enough evidence". Runs on a laptop for $0.

  • Compared keyword, semantic and hybrid search on a labelled benchmark; semantic search with a cross-encoder reranker raised ranking quality (MRR) from 0.54 to 0.964, and reached 1.00 on 38 held-out questions2.
  • Two answer checks: each quote must appear in its source, and a multilingual NLI model must agree the sentence follows from it. On held-out questions, 9 of 10 unanswerable questions were refused2.
  • Found the NLI check wrongly removed 27% of correct sentences; scoring short sentence windows cut that to 5%3.
  • Next.js interface, rate limits, threat model, hardened Docker containers; 440 Python, 54 UI and 11 browser tests in CI5.

Python, FastAPI, PyTorch, Ollama (Qwen 3.5), ChromaDB, SQLite FTS5, Next.js, TypeScript, Docker, GitHub Actions

AskUoC

A chatbot for the University of Cyberjaya that answers questions about programmes, fees, scholarships and admission from the university's own website, with a source for every answer.

  • LangGraph pipeline: query rewriting, hybrid search with RRF, reranking and relevance grading, so it says "not found" instead of guessing6.
  • Fixed wrong fee answers by storing fee tables one programme row per chunk6.
  • Accounts with roles, an admin console, fallbacks when the AI model or embeddings are unavailable, and CI with security scans and a Docker smoke test6.

Python, LangGraph, FastAPI, PostgreSQL + pgvector, Redis, Gemini, Next.js, Docker

FRESHO

A responsive online grocery store: browse and search products, a cart saved across every page, checkout with tax and delivery worked out, a shopping-list calculator and a weekly planner.

  • One shared cart module is the only code that reads or writes saved data, and it checks what it reads back, so a damaged entry can't break the totals7.
  • Form validation that explains each error per field and clears it as soon as the field is fixed7.

HTML, CSS, JavaScript (University of Cyberjaya project)
