Enterprise Knowledge AI

Hybrid-search question answering over company documents

Ask a question about company documents and get an answer that quotes the exact sentence it came from, or an honest "not enough evidence". Documents are split and indexed for both keyword and semantic search, a cross-encoder reranks the results, a local LLM writes the answer, and two checks reject any sentence the sources don't support. Built, tested and documented phase by phase, with no paid AI APIs.

How an answer is made

  1. 01Documents uploaded
  2. 02Split and indexed: keyword + semantic
  3. 03Hybrid search, then reranked
  4. 04Local LLM drafts the answer
  5. 05Every quote checked in its source
  6. 06NLI check passes, or it refuses
  • Found the NLI check wrongly removed 27% of correct sentences; scoring short sentence windows cut that to 5%3.
  • Rate limits, a threat model and hardened Docker containers that run as non-root with read-only filesystems5.

AskUoC

A university chatbot that says "not found" instead of guessing

Answers questions about programmes, fees, scholarships and admission from the university's own website, with a numbered source for every answer. A LangGraph pipeline rewrites the question, runs hybrid search with rank fusion, reranks and grades relevance before anything is answered6.

  • Fixed wrong fee answers by storing fee tables one programme row per chunk6.
  • Accounts with roles, an admin console, and fallbacks when the AI model is unavailable6.
Built with
Python, LangGraph, FastAPI, PostgreSQL + pgvector, Redis, Gemini, Next.js, Docker

FRESHO

A responsive online grocery store, built without a framework

Browse and search products, keep a cart across every page, check out with tax and delivery worked out, and plan the week with a shopping-list calculator. One shared cart module is the only code that touches saved data, and it checks what it reads back, so a damaged entry can't break the totals7.
