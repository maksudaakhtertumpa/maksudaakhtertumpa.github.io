# maksudaakhtertumpa.github.io

Personal portfolio of Maksuda Akther Tumpa: projects, background and contact.
Live at **https://maksudaakhtertumpa.github.io/**.

Plain HTML and CSS (one small script for the citation links), no build step. Hosted free on GitHub Pages:
every push to `main` publishes the site.

- `index.html`: the page
- `style.css`: styles (light and dark, mobile layout)
- `assets/`: project screenshots and the icon
- `cv/`: CV as a PDF (replace the file to update it; keep the file name)
